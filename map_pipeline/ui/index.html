Map pipeline

A real Dutch place, as a 3D model you can open in Blender or Unity
Pick a square anywhere in the Netherlands. This downloads the official open data for it — the buildings, the height of the ground, the roads, the aerial photograph — and builds a model.blend to edit and a model.fbx for Unity. Everything comes out life-size in metres, standing at its real height above sea level.

You do not need to know anything about maps or 3D modelling to use it: choose a place, press Build model, and leave the rest alone. Every setting has a ? next to it that says what it does.

What you get, and how to open it

A folder output/<name>/ holding:

model.blend — the model for editing in Blender: every layer its own collection, one object per building and tree. In the layered style the ground is a coarse terrain with the roads, walkways and lawns as objects of their own lying on it; in the survey style the roads and ground are clean quads, the ground's edges following every waterline, road edge and building.
model.fbx — the same model for Unity.
maptile_tools.py — Blender tools that keep the ground under the roads after you edit them.
aerial.png and the wall images — the textures.
metadata.json — where in the world it sits.
ATTRIBUTION.txt — the credits. Keep it with the model if you pass the model on.

Blender: open model.blend. The Maptile tab in the sidebar (N) has the tools; if it is missing, allow scripts when Blender asks, or install maptile_tools.py as an add-on. In the layered style the roads, walkways and lawns follow the terrain by themselves: reshape the terrain and they move with it. Each walkway's kerb is its CurbGenerator modifier, so edit the walkway's outline and the kerb follows. Use Blender 5 for the kerbs. In the survey style, after moving or widening a road, press Fit terrain under roads.

Unity: drag the folder into Assets. On the FBX set Scale Factor to 1, leave Convert Units on, and tick Bake Axis Conversion so nothing arrives rotated.

The centre of the square is the origin, so the model straddles 0,0. Height is measured from Dutch sea level (NAP), the same as on any Dutch map.
