Map pipeline

A real Dutch place, as a 3D model you can open in Blender or Unity
Pick a square anywhere in the Netherlands. This downloads the official open data for it — the buildings, the height of the ground, the aerial photograph — and builds a model.fbx with an aerial.png to go on it. Everything comes out life-size in metres, standing at its real height above sea level.

You do not need to know anything about maps or 3D modelling to use it: choose a place, press Build model, and leave the rest alone. Every setting has a ? next to it that says what it does.

What you get, and how to open it

A folder output/<name>/ holding four files:

model.fbx — the model itself: ground, buildings, roads, water, trees.
aerial.png — the photograph that goes on the ground.
metadata.json — where in the world it sits, for lining it up with other data.
ATTRIBUTION.txt — the credits. Keep it with the model if you pass the model on.

Blender: File → Import → FBX, and pick model.fbx. It arrives in metres, ready to edit.

Unity: drag the folder into Assets. On the FBX set Scale Factor to 1 and leave Convert Units on.

The centre of the square is the origin, so the model straddles 0,0. Height is measured from Dutch sea level (NAP), the same as on any Dutch map.
